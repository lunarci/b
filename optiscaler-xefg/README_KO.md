# JaeYun XeFG6x R3

R2의 업스케일/색상/노출 처리, Intel 프레임 생성, 최대 6배 해제, 기존 입력 시간 선택을 유지한 추가 안정성 빌드입니다.

## 추가 변경

- XeFG 자체 복사 버퍼와 동기화 객체를 소유권에 맞게 정리합니다. GPU 작업과 Intel 참조가 끝나기 전에는 해제하지 않습니다.
- 버퍼 교체 할당 실패 때 기존 버퍼 주소가 잘못 남지 않도록 처리합니다.
- 큰 지연 전환 후 자체 pacing 기록을 다시 설정하고, reset 요청을 자체 대기 도중 반영합니다. GPU fence와 Intel 내부 동기화는 유지합니다.
- descriptor heap 메타데이터의 큰 배열 생성은 전역 등록 잠금 밖에서 수행합니다. 완성된 객체만 잠금 안에서 공개합니다.
- 메모리 예산/사용량, 프로세스 메모리, 화면 출력 및 일부 대기 시간을 제한적으로 기록합니다. 측정값은 CPU 경과시간이며 실제 GPU 사용률/실행시간이 아닙니다.

## 유지 조건

최대 출력 6배(보간 5 + 원본 1), 기본 보간 수 2(출력 3배), 업스케일 비율 1.5, 기존 AMD/Intel 구성 DLL, 화질 설정을 유지합니다. DLSS5와 추가 프레임 생성 모드를 새로 결합하지 않습니다.

## 검증 범위

소스 해시, 실제 생산 코드 발췌 회귀 검증, Windows Release 빌드, DLL 내보내기 및 PDB 식별을 검증합니다. 실제 RX 9070 XT/Cyberpunk 장시간 실행과 화질 비교는 이 빌드 환경에서 수행하지 않습니다.

메모리 예산 감시는 강제 RAM 이전 기능이 아닙니다. GPU가 완료되지 않는 예외 상황에서는 자원을 강제 해제하지 않으며, 전체 swapchain 재생성이 필요할 수 있습니다. 게임 엔진과 드라이버의 메모리 문제 전체를 해결한다고 보장하지 않습니다.
