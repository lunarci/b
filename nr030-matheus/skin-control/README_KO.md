# 0.2.4 피부 구조 보정 설정 패치

움직이는 그림자가 피부에서 자글거리는 문제를 확인하기 위한 설정 패치입니다. 기본 NR 0.3.0의 `SkinStructure`를 0으로 바꿉니다. 새로운 셰이더를 설치하지 않으며, 0.2.4 ASI와 85% 입력 설정을 유지합니다. 설치된 NR/추가 모드가 정확한 대상 버전인지 먼저 검사합니다.

## 실행 순서

1. 게임과 Mod Organizer 2를 모두 종료합니다.
2. 이 ZIP을 다운로드 폴더 등 원하는 곳에 **전부 압축 해제**합니다. 게임 폴더에 덮어쓰지 않습니다.
3. 압축을 푼 폴더의 `01_APPLY_SKIN_CONTROL.cmd`를 실행합니다.
4. 평소처럼 MO2에서 게임을 실행하고, 같은 위치에서 피부에 생긴 그림자를 움직이며 확인합니다.
5. 되돌리려면 게임과 MO2를 종료하고 `02_RESTORE_SKIN_CONTROL.cmd`를 실행합니다.

대상은 기존 `C:\CYBERPUNK_ARK_PACK_MO2`입니다. 이 도구는 `mods\ARK_OptiScaler_\Root\bin\x64\plugins`와 기존 `overwrite\Root\bin\x64\plugins`의 설정을 각각 처리합니다. 없는 overwrite 설정을 만들지 않습니다. 재설치나 필수 파일 다운로드는 필요하지 않습니다.

`SkinStructure=0`은 NR의 인물 마스크를 이용하는 피부 구조 보정 채널을 끕니다. 일반 `LocalStructure`, 톤, 전체 NR 보정 강도, 시간 누적, 업스케일 배율, XeFG 설정은 변경하지 않습니다. 정상적인 피부 질감·음영 보정 효과도 줄어들 수 있습니다. 피부 그림자만 정확히 골라 제거하는 기능은 아니며, 실제 증상 개선은 아직 검증되지 않았습니다.

`UseAutoMask=0`이면 이 제어가 효과가 없어 적용을 중단합니다. 별도 설정을 임의로 켜지 않습니다. 복원은 적용 전 파일을 되돌리므로, 적용 이후 다른 NR 설정을 수정했다면 충돌을 알리고 멈춥니다. 반복 적용으로 최초 백업을 덮어쓰지 않습니다.

## 전체 로그 수집

게임과 MO2를 종료한 뒤 `03_COLLECT_FULL_LOGS.cmd`를 실행합니다. `Results` 폴더에 `MOTION_EVIDENCE-날짜-번호.zip`이 생깁니다. 요약뿐 아니라 기존 NR/추가 모드/OptiScaler 로그와 INI를 함께 담습니다. 파일은 PC에만 저장됩니다.

요약 로그에서 빠져 있던 NR 시작 설정, 시간 누적·마스크·노출 관련 기록을 확인하기 위한 자료입니다. 게임을 다시 실행하기 전에 수집하면 방금 확인한 세션을 보존할 수 있습니다.

## 선택적인 전체 강도 비교

처음에는 위 1번만 적용하세요. `optional` 폴더의 버튼은 별도 비교가 필요할 때 사용합니다.

- `SET_EFFECT_25.cmd`: 0.2.4의 전체 NR 보정 강도를 25로 설정합니다. 기존 50보다 약해집니다.
- `SET_EFFECT_50.cmd`: 전체 보정 강도를 기존 기준인 50으로 설정합니다. 모든 설정의 백업 복원 기능은 아닙니다.
- `SET_EFFECT_0.cmd`: NR 계산은 유지하면서 화면에 합성하는 NR 보정만 0으로 설정합니다. FPS·입력 지연 개선을 위한 NR 끄기 기능이 아닙니다.

각 버튼은 게임과 MO2 종료 후 실행하며, 적용 전 설정을 개별 백업합니다. SkinStructure 복원 버튼은 이 추가 모드의 EffectPercent를 바꾸지 않습니다.

## 코드 근거와 검증 범위

대상 기본 NR ASI SHA-256: `c7aad08f555bb8a7650f084c3e35aa188587060754ba0ac6538a5152c0a9f2de`.
대상 추가 모드 0.2.4 ASI SHA-256: `8983dd9ff84b2615848ef3ac04f2e31fb150737f8867e26ced33cc8a8941e58d`.

기본 NR 바이너리의 INI 읽기·UI 설명·워커 제어 전달을 대조했습니다. SkinStructure 기본값은 -1이며 LocalStructure를 따릅니다. UseAutoMask가 켜져 있으면 SkinStructure=0은 첫 번째 마스크 제어를 0으로 만들고 두 번째 LocalStructure 제어는 유지합니다. 자체 UI 설명과 워커 RVA 0x19070–0x190e5가 일치합니다.

[원 제작자 안내](https://github.com/danielblnc/DLSS-NR-on-AMD#in-game-overlay)에서도 Skin structure 조정 항목을 안내합니다. 위 기본값과 제어 전달 관계는 최신 버전 일반론이 아니라 이 패치가 대상으로 삼은 C7 바이너리를 확인한 결과입니다.

이 바이너리에서 Temporal 기본값은 1이지만 PreUpscale의 PreHistory 기본값은 0입니다. 따라서 Temporal=1만 강제해도 별도 NR 히스토리 경로가 활성화되는 것은 아닙니다. 이 패치는 히스토리 설정을 바꾸지 않습니다.

0.2.4의 국소 휘도 필터는 같은 프레임의 밝기 차이를 제한합니다. 프레임 사이에서 그림자 영역 전체의 보정이 흔들리는 문제를 완전히 막는 시간 누적 필터는 아닙니다. 이번 패치는 다른 공간 필터를 추가하지 않습니다.

검증 결과와 정확한 설정 스크립트 커밋은 CONTROL_PROVENANCE.json에 기록됩니다. 파일 변경·복원 테스트 통과는 Radeon 게임 화면의 개선을 의미하지 않습니다. 원본 0.2.4 빌드 자료는 baseline 폴더에 보관했습니다.
